# 0058. 개요 진입 때 확인한 근거만 기존 샌드박스 AI에 전달해 이전 후보를 추천한다

- 상태: 채택
- 날짜: 2026-11-08

## 상황

메모리 수급과 클라우드 정책이 변할 때 앱의 배치를 다시 검토할 이유를 개요에서 짧게 보여줘야 한다. 화면의 주기적 관측마다 AI·과금 API를 호출하거나 VM 한 대 가격을 앱 전체 절감액으로 표시하면 비용과 판단 오류가 커진다. 샌드박스 계획에 사용하는 모델·기록을 재사용하되 추천에는 Kubernetes 조사·리허설 권한이 필요하지 않다.

## 결정

- viewer GET `/v1/migration-recommendations`은 프로세스 내 단일 실행과 15분 캐시를 사용한다. 새로 들어오거나 명시적으로 새로고침할 때만 후보를 모은다. `/status`는 캐시만 읽으며 공급자나 Job을 호출하지 않는다. 실패도 같은 재생성 제한을 적용한다.
- 등록 앱 최대 8개·후보 16개·64KiB, 알려진 원본 쓰기 경로와 등록 대상 환경만 입력한다. 최근 2분의 클러스터 응답과 Ready 노드는 자원 여유의 증명이 아니다. DSN·백엔드 URL·시크릿 이름·앱 원문 스펙·행·파일 키는 AI 입력에서 제외한다.
- 검토한 template annotation `hopcharlie.dev/recommendations=v1`에서만 `hopai recommend`를 실행한다. 기존 계획과 같은 모델·관측 설정을 재사용하고 도구는 고정 스냅샷 읽기 하나만 허용한다. 신규 실행권한·클러스터 자격증명·리허설은 부여하지 않는다. annotation 없는 구버전은 `not_configured`다.
- 5분 유효 스냅샷과 1회 capability를 SHA256으로 바인딩한다. agent 인증과 nonce·snapshot·후보 ID·허용 action·원문 근거를 서버에서 재검증한다. AI는 최대 4개 후보와 후보별 기존 근거 2개를 선택하고, 앱·환경·금액·출처를 새로 만들 수 없다. 추천은 승인·이전 실행이 아니다.
- 공개 AWS 지역별 Linux m7i.large 참고 단가는 자격증명 없이 최대 4MiB/8초로 읽고 24시간 캐시한다. 지역·OS·소프트웨어·게시 시각·통화가 맞아야 하며 redirect는 허용하지 않는다. 이전 캐시와 새 공시가 모두 있을 때만 공시 변동을 비교한다. GCP API 키가 없으면 지역 단가·청구액을 추측하지 않는다.
- AWS·GCP 공식 과금 조건과 Samsung·NVIDIA의 날짜가 있는 전망은 참고 출처다. 반도체 전망을 클라우드 요금 인상률로 바꾸지 않는다.
- `PLATFORM_RECOMMENDATION_COST_FILE`은 선택적인 **운영자 입력 앱 전체 비용 견적**이다. 같은 앱·스펙 commit·환경·지역·기간, 24시간 이내, 스토리지·반출·운영·약정·용량·데이터 정책 검토가 모두 있어야 비교한다. 온프렘은 전력·장비 상각과 0보다 큰 비용도 필요하다. 누락은 0원이나 절감으로 표시하지 않는다.
- 기존 데이터 레지던시 정책에서 정확한 원본 DB·버킷의 `kr-only`/`apac` 선언을 찾아 대상 국가 제한을 보수적으로 추가한다. 한국 보관을 온프렘 전용으로 해석하지 않는다. 선언은 새 inventory의 완전성이나 실제 저장 위치 증명이 아니며 실제 이전은 기존 검증·승인을 다시 거친다.

## 검토한 대안

- 화면 polling에 AI 연결: 반복 비용과 요청 폭증 때문에 제외했다.
- 뉴스나 VM 단가로 앱 전체 이전 절감 확정: 약정·반출·운영비·장비비가 빠져 제외했다.
- 추천에 전체 리허설 재사용: 시간이 길고 필요 없는 클러스터 자격증명 접근이 생겨 별도 읽기 전용 모드를 선택했다.
- Bloom filter로 과거 판정을 승인처럼 재사용: 오탐·상태 변화를 다루지 못하므로 선택하지 않았다.

## 결과

개요의 짧은 추천과 기존 이전 화면의 준비·승인 흐름을 연결한다. 앱·대상·원본의 최신 등록을 프론트에서 다시 확인한다. 비교 가능한 비용 견적이 없으면 주로 추가 확인 또는 유지 결과를 반환하며 실제 청구·사용 메모리를 측정했다고 주장하지 않는다.

현재 API는 단일 인스턴스 메모리 캐시다. 재시작하면 callback은 복원되지 않지만 기존 Job의 15분 기록을 확인해 동일 기간의 반복 실행을 거절한다. 다중 API 인스턴스의 분산 예산 잠금은 별도 범위다. 최신 Job template·이미지·선택적 비용 파일의 운영 연결과 실제 AI 실행은 코드 테스트와 별개로 확인한다. 테스트는 provider fake와 임시 Kubernetes client를 사용하고 운영 모델을 유료 호출하지 않는다.
